# 🛒 E-Commerce Data Analysis Using Python

## Project Overview

This project demonstrates data cleaning and exploratory data analysis (EDA) on an E-Commerce dataset using Python.

The dataset was processed using Pandas, NumPy and Matplotlib.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Data Cleaning

- Rating missing values filled using Mean
- Price missing values filled using Median
- Quantity missing values removed
- Index reset after row deletion

## Visualizations

- Order ID vs Customer
- Order ID vs Category
- Order ID vs Price
- Order ID vs Quantity
- Order ID vs Product
- Customer vs Category
- Customer vs Product
- Quantity vs Customer
- Category vs Product
- Category vs Quantity
- Price vs Category
- Rating Distribution
- Product vs Quantity
- Price vs Product
- Order Date Distribution

## Key Insights

- Electronics category contributed significant sales.
- Most ratings were above 4.
- Customer purchase quantity ranged from 1–3.
- Different categories showed different purchase patterns.
